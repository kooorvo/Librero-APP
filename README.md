# LIBRERO

Logiciel de gestion pour librairies et bibliothèques. Débuté dans le cadre d'un exercice en cours de NSI.

Librero permet de 
- rechercher un livre dans un fichier `data.json` via son titre
- Attribuer une note /5
- Gérer les emprunts et connaître l'idée des personnes ayant emprunté un livre
- Ajouter ou supprimer un livre dans le fichier `data.json`


Le logiciel est codé en python. L'interface utilisateur est construite à partir de la librairie python *customtkinter*.

Deux versions du logiciel existe : 
- _Librero CLI_, qui s'utilise intégralement dans l'interpréteur de commande (dit *cmd*)
- _Librero GUI_, qui possède une interface utilisateur. (en "travaux")

Vous pouvez retrouver l'historique des modifications dans le fichier `patch_note.md` (https://github.com/kooorvo/Livres/blob/a7b6a19865f4ae445fddadebbdcb0e19629b6ffd/patch_note.md)
